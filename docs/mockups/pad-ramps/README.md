# Color ramps on iPad

These files show the card of a color ramp and the editor of a custom ramp in the Layers panel of the iPad layout. The pictures in `assets` come from the app, and `ramps.html` draws the card and the editor over them. The sample ramp, Coast, has teal sea colors, which are not mostly blue.

Run `docs/mockups/pad-ramps/render.sh` from the root of the repository to make the screens. Set `CHROME` to the path of Chromium or Chrome if the command `chromium` does not exist.

| Screen | Content |
| --- | --- |
| `card-keep` | The card of Coast on Keep, with "Fit to 12 bands" and "Edit ramp…". |
| `card-new` | The card on New, with the stepper "Bands" and "Make 10 bands". |
| `editor` | The top of the editor of Coast, with the switch "Sea level" and the line of sea level between two colors. |
| `editor-end` | The end of the editor, with "Add color", "Reverse colors", and "Save ramp". |
